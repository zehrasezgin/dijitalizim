DIJITAL.IZIM - ÜCRETSİZ WEB SİTESİ KURULUMU

1) Bu klasördeki index.html ve assets klasörünü olduğu gibi kullanın.

EN KOLAY ÜCRETSİZ YAYINLAMA - GITHUB PAGES

1. github.com üzerinden ücretsiz hesap açın.
2. Sağ üstten "+" > "New repository" seçin.
3. Repository adına: dijital-izim-site yazın.
4. "Public" seçin ve "Create repository" deyin.
5. "uploading an existing file" bağlantısına tıklayın.
6. index.html dosyasını ve assets klasörünü yükleyin.
7. "Commit changes" deyin.
8. Repository > Settings > Pages bölümüne girin.
9. "Build and deployment" altında "Deploy from a branch" seçin.
10. Branch: main / folder: /(root) seçin ve Save deyin.
11. Birkaç dakika sonra siteniz şu yapıda açılır:
    https://KULLANICIADINIZ.github.io/dijital-izim-site/

ALAN ADI EKLEME (İSTEĞE BAĞLI)
- Hosting için ödeme yapmanız gerekmez.
- Sadece dijitalizim.com gibi bir alan adı satın alabilirsiniz.
- GitHub Pages > Custom domain alanına alan adınızı girin.
- Alan adı firmanızdaki DNS kayıtlarını GitHub'ın gösterdiği şekilde bağlayın.

SİTEDE DEĞİŞTİRMENİZ GEREKENLER
- Instagram linki: index.html içinde "https://www.instagram.com/dijital.izim/" aratın.
- Metinleri doğrudan index.html içinden değiştirebilirsiniz.
- Renkler: assets/style.css içinde #2e8cff (mavi) ve #ff8a00 (turuncu).
- Logo: Şimdilik yazı logo kullanılıyor. Elinizde PNG/SVG logo varsa assets klasörüne ekleyebilirsiniz.
- GA4 ve Meta Pixel kodları için index.html dosyasının en altında not bırakıldı.
